# 多语言国际化 (i18n) 设计文档

**日期**: 2026-08-18  
**状态**: 待审批  
**范围**: 前端 React + TypeScript 项目

---

## 目标

为 LearnHub 前端添加中英文多语言支持，用户可通过顶部导航栏切换语言，语言偏好持久化到 localStorage。

---

## 架构选型

### 技术方案：react-i18next + namespace 分模块

**理由**：
- react-i18next 是 React 生态最成熟的 i18n 库，API 简洁（`useTranslation` hook）
- namespace 分模块便于维护，300+ 字符串按功能域拆分
- 支持懒加载（后续可扩展）
- 社区活跃，类型安全

**依赖包**：
```json
"i18next": "^23.0.0",
"react-i18next": "^14.0.0",
"i18next-browser-languagedetector": "^7.0.0"
```

## 核心实现

### 1. i18n 初始化 (`src/i18n/index.ts`)

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

import * as commonEn from './locales/en/common.json';
import * as commonZh from './locales/zh/common.json';
// ... 其他 namespace

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { common: commonEn, auth: authEn, tutorials: tutorialsEn, ... },
      zh: { common: commonZh, auth: authZh, tutorials: tutorialsZh, ... }
    },
    fallbackLng: 'en',
    supportedLngs: ['en', 'zh'],
    interpolation: { escapeValue: false },
    ns: ['common', 'auth', 'tutorials', 'admin', 'wizard', 'share', 'chat']
  });

export default i18n;
```

### 2. LanguageSwitcher 组件 (`src/i18n/LanguageSwitcher.tsx`)

```typescript
const LanguageSwitcher = () => {
  const { i18n } = useTranslation();
  const currentLang = i18n.language;
  
  const toggleLanguage = () => {
    const newLang = currentLang === 'en' ? 'zh' : 'en';
    i18n.changeLanguage(newLang);
    localStorage.setItem('language', newLang);
  };

  return (
    <button onClick={toggleLanguage} className="...">
      {currentLang === 'en' ? '🇨🇳 中文' : '🇬🇧 English'}
    </button>
  );
};
```

### 3. App.tsx 集成

```typescript
// 导航栏已有 ThemeToggle，在其旁边添加 LanguageSwitcher
// i18n 已在 i18n/index.ts 全局初始化，无需额外 Provider
```

### 4. 组件迁移规则

| 原模式 | 新模式 |
|--------|--------|
| `"Failed to post comment"` | `t('errors.comment_failed', { ns: 'common' })` |
| `"No chapters yet"` | `t('no_chapters', { ns: 'tutorials' })` |
| `"Step 1: ..."` | `t('step_1_title', { ns: 'wizard' })` |
| `"Chapter {{n}}"` | `t('chapter', { ns: 'tutorials', n: 3 })` |

| 内容 | 原因 |
|------|------|
| Claude 3 Opus / Sonnet / Haiku | Anthropic 产品名 |
| API Base URL / API Key | 技术字段名 |
| Google / GitHub | 第三方服务名 |
| Twitter / LinkedIn / WeChat | 社交媒体名 |
| 数学符号、代码示例 | 技术内容 |
| 用户输入内容 | 动态数据 |

## 实施步骤

1. 安装依赖：`cd src/frontend && npm install i18next react-i18next i18next-browser-languagedetector`
2. 创建 `src/i18n/` 目录，编写初始化配置和 LanguageSwitcher
3. 按 namespace 创建 en/zh 翻译 JSON 文件（7 个）
4. 在 App.tsx 导航栏集成 LanguageSwitcher
5. 逐个组件替换硬编码字符串为 `t()` 调用
6. 测试中英文切换，验证所有页面无遗漏
